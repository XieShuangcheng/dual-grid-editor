# 双网格地图编辑器 · DualGrid Editor

基于 Godot 4 的 2D 双网格地图编辑器插件。本项目包含插件源码、调试图集和测试场景，可用于在编辑器中绘制草地与土地边界。

作者：**XieShuangcheng**


## 环境

- 开发环境：Godot **4.6.2**，使用 GDScript，无需安装 .NET SDK。
- 当前项目使用 Mobile 渲染器，Windows 图形驱动配置为 D3D12。
- 本项目主要用于编辑器内测试，尚未配置运行主场景。

## 已有功能

- 画笔绘制与擦除，拖动时补齐经过的格子。
- 矩形区域绘制与擦除，拖动预览、松开提交。
- 油漆桶按上下左右四方向填充或擦除连通区域。
- 油漆桶范围可配置，默认起点 `(-16, -16)`，大小 `32 × 32`；宽高各限制为 `1–256`。
- 编辑操作支持撤销、重做，`Esc` 可取消当前手势。
- 鼠标悬停格子、矩形区域和油漆桶范围预览。
- 根据相邻四个逻辑格生成 16 种显示掩码，支持图集绘制与纯色回退。
- 地图数据保存在场景节点的 `grass_cells` 属性中。

## 快速开始

1. 在 Godot 项目管理器中导入根目录的 `project.godot`。
2. 打开项目，在“项目 → 项目设置 → 插件”中确认 **DualGrid Editor** 已启用；本项目已配置默认启用。
3. 打开 `test_map.tscn`，选中场景树中的 `DualGridMap` 节点。
4. 在 2D 视图顶部的 **DualGrid** 工具栏打开地形编辑开关。
5. 选择画笔、矩形或油漆桶工具，开始编辑。
6. 使用 `Ctrl + S` 保存场景。

| 操作 | 效果 |
| --- | --- |
| 鼠标左键 | 绘制草地；矩形和油漆桶在松开时提交 |
| 鼠标右键 | 擦除草地；矩形和油漆桶在松开时提交 |
| 拖动画笔 | 连续绘制或擦除 |
| 拖动矩形 | 预览选区，松开后应用 |
| `Esc` | 取消当前操作；画笔恢复至本次笔划开始前 |
| `Ctrl + Z` | 撤销 |
| Godot 的重做快捷键 | 重做，按编辑器快捷键设置执行 |

油漆桶仅处理设定范围内、与点击位置同类且连通的格子。选择油漆桶后，可通过工具栏的范围按钮修改起点和尺寸；当前范围设置只在本次插件会话中有效。

## 图集配置

在 `DualGridMap` 节点的检查器中设置：

| 属性 | 说明 |
| --- | --- |
| `cell_size` | 逻辑格尺寸，默认 64 |
| `grass_color` / `dirt_color` | 纯色草地与土地背景颜色 |
| `show_grid` | 是否显示显示网格边框 |
| `terrain_atlas` | 地形图集纹理 |
| `atlas_tile_size` | 图集中单块瓦片的像素尺寸，默认 `32 × 32` |
| `atlas_layout` | 图集排列方式：参考布局、掩码顺序或自定义 |
| `mask_to_atlas_index` | 自定义布局下，16 个掩码对应的瓦片索引 |

掩码位定义为左上 `1`、右上 `2`、左下 `4`、右下 `8`。瓦片索引按从左到右、从上到下计数，从 `0` 开始。

- **Reference 4x4**：使用代码中的参考布局映射，要求图集为 4 列 × 4 行。
- **Mask Order 4x4**：按掩码 `0–15` 顺序排列，要求图集为 4 列 × 4 行。
- **Custom**：通过 `mask_to_atlas_index` 提供完整的 16 项映射。

掩码 `0` 只绘制土地背景；缺少图集或图集配置无效时，其余掩码使用纯色分块回退。像素画素材建议将节点的 Texture Filter 设为 **Nearest**，测试场景已设置。

## 文件结构

| 路径 | 用途 |
| --- | --- |
| `project.godot` | Godot 项目设置及插件启用配置 |
| `test_map.tscn` | 地图编辑测试场景 |
| `addons/dual_grid_editor/plugin.cfg` | 插件注册信息 |
| `addons/dual_grid_editor/plugin.gd` | 编辑器工具栏、输入、预览和撤销重做 |
| `addons/dual_grid_editor/runtime/dual_grid_map.gd` | 地图数据、坐标转换和绘制 |
| `addons/dual_grid_editor/core/dual_grid_solver.gd` | 四角掩码与受影响显示格计算 |
| `addons/dual_grid_editor/core/dual_grid_flood_fill.gd` | 有限范围内的连通区域填充 |
| `addons/dual_grid_editor/art/dual_grid/` | 地形纹理与调试图集 |

## 在其他项目中使用

1. 将整个 `addons/dual_grid_editor/` 文件夹复制到目标 Godot 项目的同名目录下。
2. 在目标项目的插件设置中启用 **DualGrid Editor**。
3. 新建 `DualGridMap` 节点，配置图集后使用工具栏编辑。
4. 保存包含该节点的场景。游戏运行时仍需保留插件目录下被地图脚本引用的运行时和核心脚本。

## 版本管理说明

`.gitignore` 已排除 Godot 缓存、常见导出目录、本地编辑器设置和临时文件。请保留 `.gd.uid`、资源的 `.import` 配置、素材源文件和场景文件，以维持资源引用及导入设置。

当前实现以单一草地占用数据为基础，尚未提供多地形类型、碰撞生成或导航生成。插件描述文件中的版本号为 `0.1.0`；实际功能请以当前源码为准。
